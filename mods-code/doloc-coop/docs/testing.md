# DolocCoop 测试策略

## 三级测试金字塔

### L1:单机双开 + 回环传输(日常开发主力,零 Steam 依赖)

为此专门做了 `LoopbackTransport`(本机 UDP 27851,绕过 Steam):

1. **直接双击 `DolocTown.exe` 启动两个实例**(不经 Steam 客户端菜单,绕开单实例限制;
   Steam 客户端保持运行即可,两个实例都会挂到你同一个账号上——回环模式不在乎)。
2. 实例 A:进存档(**存档位 1**)→ 按 **F6** = 回环主机。
3. 实例 B:进存档(**存档位 2**,避免存档文件写冲突)→ 按 **Ctrl+F6** = 连接本机主机。
4. 两边走动,看 `BepInEx\LogOutput.log` 与游戏内幽灵(对方位置的半透明分身 + 头顶 ID)。

注意事项:
- 两个实例共用同一个 LocalLow 目录,**务必用不同存档位**;
- 如果第二个实例被游戏拒绝启动(个别 Steam 游戏会检测),备选方案:
  用另一个 Windows 用户账户跑第二个实例,或把游戏目录整个复制一份跑副本;
- 回环模式没有断线检测/重传,仅验证同步逻辑,不验证网络质量。

### L2:双机 + Steam 真通路(里程碑验收用)

Steam 大厅 + P2P 的完整链路(F9 建大厅 → F4 邀请 → 好友接受)需要
**两个各自拥有游戏的 Steam 账号 + 两台机器**:

- Steam 家庭共享**不支持**同一份游戏两人同时玩,所以要么第二份拷贝,要么拉一个也有游戏的朋友;
- 你的 Mac 不行(游戏仅 Windows);现实路线:找朋友做每周一次的真通路冒烟测试,
  平时全部走 L1 回环。
- 架构上 SteamTransport 和 LoopbackTransport 实现同一个 ITransport,
  L1 验证过的同步逻辑在 L2 只需验证传输层本身(大厅、邀请、NAT 中继)。

### L3:异地公网(发布前)

朋友异地实测 Steam P2P 中继质量(AllowP2PPacketRelay),观察延迟对 15Hz 状态同步的影响;
鸭科夫的经验:国内玩家可能需要加速器,这是 Steam 中继的固有情况,文档里向用户说明即可。

## v0 验收清单(当前版本)

- [ ] L1 双开:B 能在 A 的世界里看到幽灵,位置跟随流畅(插值 12/s)
- [ ] 幽灵朝向翻转正确(FacingLeft)
- [ ] 一方退出,另一方幽灵消失(回环模式暂靠会话销毁)
- [ ] F9 单机建大厅不报错、F4 弹出 Steam 邀请覆盖层(不需要第二人也能冒烟)
- [ ] 挂机 10 分钟无异常日志刷屏、无明显 GC 卡顿

## 当前快捷键

| 键 | 功能 |
|----|------|
| F9 | Steam:创建好友大厅 |
| F4 | Steam:好友邀请覆盖层 |
| F6 | 回环:本机做主机 (UDP 27851) |
| Ctrl+F6 | 回环:连接 127.0.0.1 主机 |
| F5 | (DolocDevTools) 热重载 Mod 列表 |
| F1 | 官方调试控制台 |
